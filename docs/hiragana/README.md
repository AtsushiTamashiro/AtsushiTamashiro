# ✏️ ひらがな かきかた

5歳の子が「◯ の かきかた なんだっけ？」と思ったときに、ひらがなの書き順を
大きなアニメーションで見せる学習アプリです。

- **こえで きく** — 🎤ボタンを押して「あ の かきかた おしえて」「き って どう かくの？」
  「ちいさい つ」などと話すと、その字の書き順アニメーションを表示(Web Speech API / ja-JP)
- **50音表** — せいおん・だくおん/はんだくおん・ちいさい字の3タブ。タッチでも表示
- **書き順アニメーション** — 白紙から1画ずつ描き、番号バッジ(色分け)付き。描き終わると自動で繰り返す
- 🐢ゆっくり/ふつう切替、◀▶で前後の字へ、🔊で読み上げ
- 一度開けばオフラインでも動作(Service Worker)

## 対応ブラウザ

音声入力は Chrome(Android/PC)・Safari(iPhone/iPad) で動作します。
Fireタブレット(Silk)など非対応ブラウザでは、50音表のタッチ操作のみ使えます。
