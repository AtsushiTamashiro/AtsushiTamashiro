# モインクラフト

ブロックをこわすたびに **「モイン!」** と大声で叫ぶ、ブラウザで遊べるブロック建築ゲームです。
敵はいません。モイン村のやさしい村人たちと話しながら、自由にものづくりができます。

- 公開URL(GitHub Pages): https://atsushitamashiro.github.io/AtsushiTamashiro/moin/
- インストール不要。Three.js を `vendor/` に同梱しているので外部 CDN にも依存しません。
- PC(マウス+キーボード)とスマホ・タブレット(タッチ操作)の両方に対応。

## 操作

| PC | スマホ・タブレット | 操作 |
| --- | --- | --- |
| W A S D | 左下をなぞる | 移動 |
| マウス | 右側をなぞる | 見回す |
| 左クリック長押し | ⛏ 長押し | ブロックをこわす →「モイン!」 |
| 右クリック | 🧱 | ブロックを置く |
| Space | ⤒ | ジャンプ(水中では泳ぐ) |
| Shift | スティックを端まで倒す | ダッシュ |
| F | 🕊 | 飛ぶ(飛行中は Space 上昇 / Shift 下降) |
| 1〜9 / ホイール | ホットバーをタップ | ブロックを選ぶ |
| E / 村人をクリック | 💬 / 村人をタップ | 話す |
| I | 🎒 | もちもの |
| H | 🏠 | 村(スタート地点)にもどる |

## 「モイン!」の声

設定画面で声の種類を選べます。

- **おまかせ** — 録音があれば自分の声、なければ端末の日本語読み上げ、それもなければ合成ボイス
- **端末の読み上げ声** — ブラウザの音声合成で毎回ちがう高さで叫ぶ
- **モイン合成ボイス** — Web Audio のフォルマント合成で「モ・イ・ン!」
- **録音した自分の声** — 🎙 ボタンで 1.6 秒録音。こわすたびに自分(や家族)の声で叫ぶ

近くの村人も、つられて吹き出しで「モイン!」と返してくれます。

## そのほか

- 島は毎回ランダムに生成(山・雪・砂浜・海・森)。中央付近にモイン村があります
- 約10分で昼と夜がめぐります(夜でも敵は出ません)
- こわした・置いたブロック、持ち物、位置は端末内(localStorage)に自動保存
- 設定の「クリエイティブ」でブロック無限・すばやく採掘
