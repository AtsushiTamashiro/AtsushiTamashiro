# リアルおじさん用の素材フォルダ

ここにファイルを置くと、リアルおじさんが差し替わります。何も置かなくても動きます(仮の描き顔 + 端末の読み上げ声)。

## 顔写真
- `oyaji-face.jpg` … 正面から顔が大きく写った写真。置くと全員の端末で使われます。
- 端末ごとに変えたいときは、ゲーム内の ⚙️ せってい → 「リアルおじさんの顔写真」から選べます(その端末の中だけに保存)。
- ご本人、または使うことに同意してくれた人の写真だけを使ってください。公開リポジトリに置いた写真は、誰でも見られます。

## 人間の声(録音ファイル)
`voice/` に mp3 を置くと、読み上げ音声のかわりに再生されます。ファイルがないセリフだけ読み上げになります。
