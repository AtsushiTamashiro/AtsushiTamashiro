# 🥁 エイサー道ジュネーなう 読谷村

沖縄県読谷村の旧盆3日間(ウンケー・ナカビ・ウークイ)に各字の青年会が行う
**道ジュネー(エイサーの練り歩き)の現在地** を地図上で共有・閲覧できる Web アプリです。

「あの音はどこから?」「今どの通りにいる?」——音や人づてで道ジュネーを
追いかける沖縄の夏を、みんなの位置報告でもっと楽しく。

## 機能

- 🗺️ **リアルタイムマップ** — 各青年会の現在地をマーカーで表示(道ジュネー中は赤くパルス)
- 🧭 **軌跡表示** — その日の移動ルートを点線で表示。どの方向へ進んでいるかが分かる
- 📍 **位置報告** — GPS または地図タップで現在地を報告。状況(道ジュネー中/準備中/休憩中/終了)とひとことコメント付き
- 📋 **青年会リスト** — 地域フィルタ・「道ジュネー中のみ」絞り込み。タップで地図がその位置へ移動
- ⏱️ **鮮度表示** — 最終報告からの経過時間を表示し、60分以上古い情報はグレー表示
- 🏮 **旧盆カレンダー** — ヘッダーに「旧盆◯日目 ウンケー」などを自動表示

## 使い方(閲覧する人)

ページを開くだけです。地図上のマーカーをタップすると、青年会名・状況・
最終報告時刻・コメントが見られます。

## 使い方(位置を報告する人)

1. 画面下の「📍 位置を報告」をタップ
2. 青年会と状況を選択
3. 「GPSで現在地取得」または「地図をタップして指定」で位置を設定
4. 「報告する」で送信

## 動作モード

| モード | 条件 | 共有範囲 |
|---|---|---|
| **デモモード** | 初期状態(設定不要) | 同じ端末・ブラウザ内のみ(localStorage) |
| **リアルタイム共有モード** | `firebase-config.js` を配置 | 全ユーザー間で即時共有 |

全ユーザーでの共有を有効にするには、`firebase-config.example.js` を
`firebase-config.js` にコピーし、Firebase プロジェクトの設定値を記入してください。
手順の詳細はサンプルファイル内のコメントを参照。

## 公開方法(GitHub Pages)

リポジトリの **Settings → Pages** で
「Deploy from a branch」→ 対象ブランチの `/docs` フォルダを選択するだけで公開できます。
ビルド不要の静的サイトです。

## データのメンテナンス

- **青年会の追加・修正**: `js/data.js` の `KAI_LIST` を編集
  (読谷村の各字18団体を登録済み。座標は公民館周辺の概算値なので実運用前に確認を推奨)
- **旧盆の日程(毎年更新)**: `js/data.js` の `KYUBON_DAYS` を編集(2026年は 8/25〜8/27)
- **情報が古いと見なす時間**: `js/data.js` の `STALE_MINUTES`

## 技術構成

- HTML / CSS / Vanilla JavaScript(ビルド不要)
- [Leaflet](https://leafletjs.com/) 1.9.4(`vendor/leaflet/` に同梱)+ OpenStreetMap タイル
- Firebase Realtime Database(オプション)
