# 琉球道中記 〜読谷山から首里へ〜

琉球王国時代を舞台にした、ブラウザで遊べる 3D アクションゲームです。
読谷山(ユムタン)の百姓・**樽金(タルガニ)** となり、海賊の襲来を王府に知らせるため、
北谷(チャタン)の浜、浦添(ウラシー)の森を抜けて首里城を目指します。

- 公開URL(GitHub Pages): https://atsushitamashiro.github.io/AtsushiTamashiro/ryukyu/
- 動作環境: WebGL に対応した PC ブラウザ(Chrome / Edge / Safari / Firefox)。スマホ・タブレットはタッチ操作に対応。
- インストール不要。外部 CDN にも依存しません(Three.js を `vendor/` に同梱)。

## ゲームの流れ

| 地域 | 内容 |
| --- | --- |
| 読谷山 | 赤瓦の集落とサトウキビ畑。長老から使命を託される。イノシシ・ハブ・海賊の斥候 |
| 北谷 | 海賊が上陸した浜。沖に海賊船、浜に野営地。海人(ウミンチュ)から **六尺棒** を授かる |
| 浦添 | 古いグスクの石垣が残る森。山賊と大男が待ち構える |
| 首里 | 石畳の坂道、守礼門、歓会門。御庭(ウナー)で **海賊頭・黒鮫** と決戦 |

進むにつれて朝 → 昼 → 夕暮れと日が傾き、首里城には夕日の中で辿り着きます。

## 操作

| PC | 操作 |
| --- | --- |
| W A S D | 移動 |
| マウス | 視点(画面クリックでマウス固定)、ホイールで距離 |
| 左クリック / J | 攻撃(三段連撃。素手:突き・突き・前蹴り/棒:薙ぎ・薙ぎ・突き) |
| 右クリック / L | 防御。敵の攻撃が当たる直前に構えると **見切り**(敵が崩れる) |
| Shift / K | 回避の前転(無敵時間あり) |
| Space | 跳躍 |
| Q / Tab | 注目(ロックオン) |
| R | 奥義「旋風」(気ゲージが満タンのとき) |
| E | 話す |
| Esc | 一時停止 |

スマホでは左側をドラッグで移動、右側をドラッグで視点、画面のボタンで攻撃・回避などを行います。

## 戦闘のしくみ

- 敵の頭上に **!** が出たら攻撃の合図。防御・回避・見切りで対処します。
- 地面に **赤い円** が出る大技は防御できません。前転で範囲外へ。
- 攻撃を当てる・見切る・ぎりぎりで回避すると **気** がたまり、満タンで奥義が使えます。
- 道中の **拝所(ウガンジュ)** で体力が回復し、倒れてもそこから再開できます(ブラウザに自動保存)。
- サーターアンダギーを拾うと体力が回復します。

## ファイル構成

```
docs/ryukyu/
├── index.html          画面・UI・スタイル
├── js/
│   ├── main.js         ゲーム進行・入力・カメラ・物語・UI
│   ├── world.js        地形(道・海・丘)、集落、首里城、植生、当たり判定
│   ├── characters.js   人型・イノシシ・ハブのモデルと手続き的アニメーション
│   ├── entities.js     プレイヤー、敵AI、投石、アイテム、村人
│   ├── fx.js           火花・砂煙・炎・衝撃波
│   ├── audio.js        琉球音階の三線風BGMと効果音(WebAudioで合成)
│   └── util.js         乱数・ノイズ・補間
└── vendor/three.module.min.js   Three.js r170(MIT License)
```

モデル・音はすべてプログラムで生成しているため、画像や音声ファイルはありません。

## ローカルで遊ぶ

ES モジュールを使うため、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
cd docs
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ryukyu/ を開く
```

※ 物語は史実をもとにしたフィクションです。
