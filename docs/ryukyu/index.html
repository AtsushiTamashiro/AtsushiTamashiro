〜 読谷山から首里へ 〜

琉球道中記

時は十六世紀、琉球王国。読谷山の沖に海賊船が現れた。
百姓・樽金(タルガニ)は、王府に急を知らせるため、
北谷の浜、浦添の森を抜け、首里城を目指す——。

操作説明

W A S D移動(矢印キーでも可) マウス視点の回転(画面クリックでマウスを固定)/ ホイールで距離 左クリック / J攻撃 — 連打で三段の連撃 右クリック / L防御(押し続ける)— 敵の攻撃が当たる直前に構えると「見切り」 Shift / K回避の前転(無敵時間あり・気力を消費) Space跳躍 Q / Tab注目(ロックオン)の切り替え R奥義「旋風」— 気が満ちたときに使える E話す / 会話を進める Esc一時停止
・敵の頭上に ! が出たら攻撃の合図。防御か回避で備えよう。
・「見切り」に成功すると敵が崩れ、与えるダメージが大きくなる。
・赤い円は受け止められない大技。前転で範囲の外へ逃れよう。
・道中の拝所(ウガンジュ)で体力が回復し、倒れてもそこから再開できる。
・スマホ・タブレットでは画面のボタンで操作できます。
